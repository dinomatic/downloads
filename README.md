# downloads

Child themes and demo import data for DinoMatic themes.

## Contents

Each folder is one product, containing its child theme (source + ready-to-upload `.zip`) and, where available, demo import data.

```
akurai/
  akurai-child/        child theme source
  akurai-child.zip      upload via Appearance > Themes > Add New > Upload Theme
  demo-import/           akurai.xml, akurai.dat, akurai.wie, akurai.png

fxt/
  fxt-child/
  fxt-child.zip
  demo-import/           fxt.xml, fxt.dat, fxt.wie, fxt.png

sikika/
  sikika-child/
  sikika-child.zip
  (no demo import data)

spinoko/
  spinoko-child/
  spinoko-child.zip
  demo-import/           content.json
```

## Installing a child theme

Upload the product's `.zip` via **Appearance > Themes > Add New > Upload Theme** in the WordPress dashboard, then activate it. The parent theme must already be installed.

## Importing demo content

Use the parent theme's recommended demo importer (e.g. One Click Demo Import) with the files in the product's `demo-import/` folder.
